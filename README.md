# ReactCRM

Forge CRM React/Vite front end.

## Commands

- `npm ci`
- `npm run lint`
- `npm run build`
- `npm run dev`

## Notes

- Mobile uses a fixed 1200px desktop canvas with pinch-zoom enabled.
- Phone-service controls that require a real communications provider are disabled until one is connected.
- SMS and email compose actions hand off to the device/browser handlers rather than pretending a message was sent inside the demo UI.
